# DOKUMENTASI SISTEM INFORMASI KALENDER AKADEMIK (SI-KALAKAD)

## 1. Analisis Kebutuhan Sistem
Sistem ini memfasilitasi mahasiswa dan bagian akademik perguruan tinggi dalam:
- Mengakses kalender terpadu secara real-time.
- Menyaring agenda berdasarkan kategori penting (Ujian, KRS, Keuangan).
- Menandai agenda penting ke daftar pengingat pribadi.

## 2. Model Pengembangan SDLC
Menggunakan model **Waterfall (Air Terjun)** terstruktur:
1. Analisis Kebutuhan (Requirement Analysis)
2. Perancangan Sistem & Basis Data (System & Database Design)
3. Implementasi Pemrograman (Implementation / Coding)
4. Pengujian Sistem (System Testing)
5. Penerapan & Pemeliharaan (Deployment & Maintenance)

## 3. Kamus Data & Relasi
Terdiri dari 5 tabel utama: `users`, `categories`, `events`, `user_bookmarks`, dan `notifications`.
